## 1. Регулярные выражения для токенов

| Токены | Регулярное выражение |
|---|---|
| Ключевые слова (`KW_FUNCTION`, `KW_IF` и др.) | Отдельные литералы: `function`, `if`, `while` и т. д. |
| `IDENT` | `[a-zA-Z][a-zA-Z0-9]*` |
| `INT` | `0 \| [1-9][0-9]*` |
| `WS` | `[ \t\r\n]+` |
| `COMMENT` | `//[^\r\n]*` |
| Разделители и операторы | `( ) [ ] { } , ; + - * / == != <= >= < > =` |

Ключевые слова имеют приоритет над идентификаторами. Для операторов используется принцип максимального совпадения (*maximal munch*), при котором выбирается наиболее длинный подходящий оператор.

## 2. Размер автоматов

| Этап | Количество состояний |
|---|---:|
| НКА (алгоритм Томпсона) | 133 |
| ДКА до минимизации | 79 |
| ДКА после минимизации | 76 |

Минимизация объединяет эквивалентные состояния, уменьшая размер автомата без изменения распознаваемого языка.
